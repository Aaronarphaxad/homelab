# Infrastructure & Services

This section contains the practical build and service guides for the homelab.

These pages are where I document the repeatable setup steps and the troubleshooting notes I want to keep handy.

## What belongs here

Each guide should capture:

- what the service is for
- the setup path that worked
- the failure modes I hit
- the checks I use to prove it is working

## Update rule

Service setup instructions should live in the relevant service page only.

Inventory and subnet details should stay in Architecture so those details do not need to be maintained in multiple places.
